# Decisions

One file per decision that a design left open: what was decided, why, and how to reverse it. Newest first.

- [lift-revision-apart.md](lift-revision-apart.md): lift changes move `liftRevision`, not `libraryRevision`.
- [lift-state-period.md](lift-state-period.md): a lift is read as of its newest set up to the period's end.
- [lift-profile-mass.md](lift-profile-mass.md): relative strength may use the profile's body mass, at the widest error.
- [lift-set-key.md](lift-set-key.md): a set is keyed by date, exercise, equipment and set order.
- [lift-connector-writes.md](lift-connector-writes.md): the connector may not save lift logs yet.
- [lift-time-precision.md](lift-time-precision.md): `timePrecision` is `set` or `session`.
- [lift-reimport.md](lift-reimport.md): a re-imported set replaces the stored one.
